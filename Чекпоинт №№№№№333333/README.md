# «Отклик» — платформа доверительных анонимных обращений
> Проект разработан в рамках хакатона «Кубок Федерации» по кейсу средней общеобразовательной школы (буллинг, психологическое и физическое давление).

Платформа решает проблему сокрытия и формального «гашения» конфликтов на уровне школы, обеспечивая безопасный канал связи заявителя с городскими службами психологической и правовой помощи в обход школьной администрации.

---

## 🚀 1. Инструкция по быстрому запуску (Docker)

Проект полностью контейнеризирован и разворачивается **одной командой** из чистого клона:

\`\`\`bash
docker compose up --build
\`\`\`

После завершения сборки сервис доступен по адресу:
👉 **http://localhost:5000**

## 🛡️ 3. Модель приватности и безопасности (Раздел 6 ТЗ)

1. **Принцип нулевого доверия к персональным данным:**
   - Сервис не запрашивает и не сохраняет имя, телефон, адрес, номер школы или класс заявителя.
   - IP-адреса и User-Agent **не связываются с обращением и не сохраняются в базе данных**.
   - Сторонние аналитические трекеры (Яндекс.Метрика, Google Analytics) полностью отсутствуют.
2. **Очистка метаданных изображений (EXIF / GPS):**
   - Все прикрепляемые скриншоты и фотографии автоматически обрабатываются библиотекой Pillow на сервере: из них вырезаются метаданные камеры, EXIF и GPS-координаты.
3. **Строгое разграничение доступа:**
   - **Оператор** видит только исходный текст для первичной сортировки. Доступа к переписке эксперта с заявителем у него нет.
   - **Эксперт** не знает личности заявителя ни на одном из этапов.
   - **Администратор** не видит текстов обращений и переписки (в журнал аудита и CSV-выгрузку попадают только агрегаты и метаданные).

## 🔑 4. Принятые решения по трек-номерам и уведомлениям (Разделы 4.7 и 4.8)

* **Формат трек-номера:** `ОТК-XXXX-XXXX` (8 значащих символов).
* **Алфавит без коллизий:** Используется набор `23456789ABCDEFGHJKMNPQRSTUVWXYZ` (полностью исключены путающиеся символы `0/O`, `1/I/l`).
* **Криптостойкость:** Генерация осуществляется системным генератором случайных чисел `secrets`.
* **Защита от перебора (Rate Limiting):** На проверку статуса установлено ограничение — не более 5 попыток в минуту с задержкой при превышении.
* **Уведомления без деанонимизации:**
  - Заявитель может сохранить прямую ссылку-закладку на своё обращение.
  - Поддерживается добровольное поле экстренного контакта (телефон/Telegram), которое хранится отдельно и доступно исключительно оператору в кризисных ситуациях.

## 🆘 5. Кризисный сценарий и механизм экстренного реагирования (Раздел 5.3)

* **Мгновенная детекция:** Система анализирует текст в реальном времени. При наличии триггеров насилия, угрозы жизни или суицида пользователю сразу выводится плашка с прямыми бесплатными телефонами экстренных служб (**112** и **8-800-2000-122**) без блокировки ввода.
* **Приоритет вне очереди:** В кабинете оператора кризисные обращения поднимаются на первое место со специальным бейджем `⚠️ Кризисное`.
* **Решение открытой задачи 5.3 (Связь с правоохранительными органами):**
  - При возникновении непосредственной угрозы жизни ребёнка оператор переводит тикет в режим «Межведомственное содействие».
  - Заявителю в чат направляется защищенный запрос с объяснением: *«Твоей жизни может угрожать опасность. Чтобы привлечь городскую службу защиты детей, подтверди согласие на передачу контакта»*.
  - Данные передаются только по явному клику заявителя, сохраняя фундаментальное доверие к анонимности сервиса.
